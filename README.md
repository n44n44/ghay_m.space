# Ghaym Space | غيم سبيس 🛍️ ☁️
> سوق المكلا الإلكتروني الأول المتكامل متعدد البائعين (Mukalla #1 Multi-Vendor E-Marketplace)

منصة تجارة إلكترونية متكاملة تخدم مدينة المكلا ومحافظة حضرموت في الجمهورية اليمنية. تربط المتاجر المعتمدة والأسر المنتجة بالمشترين مع نظام توصيل محلي فوري وخيارات دفع محلية معتمدة.

---

## 🌟 البوابات والأنظمة المتكاملة (Ecosystem Portals)

1. **سوق الزبائن الرئيسي (`index.html`)**:
   - تطبيق ويب تفاعلي SPA يضم 22 واجهة رئيسية تغطي التصفح، الأقسام، سلة التسوق، الدفع، وتتبع الطلبات.
2. **لوحة تحكم التاجر الشريك (`merchant_dashboard.html`)**:
   - واجهة متخصصة للتاجر لإدارة المنتجات، متابعة الطلبات، الإيرادات، والمحفظة المالية.
3. **لوحة الإدارة العليا والمركزية (`admin_dashboard.html`)**:
   - إدارة التجار، المتاجر، السائقين، العمولات، والتقارير والشكاوى.
4. **بوابة كابتن التوصيل (`delivery_portal.html`)**:
   - مخصصة لمناديب التوصيل لاستلام الشحنات، تتبع العناوين، وتحصيل مبالغ الدفع عند الاستلام.

---

## ⚡ الميزات التقنية الرئيسية (Key Features)

- **نظام الترجمة الفوري ثنائي الاتجاه (Smart i18n)**: دعم كامل للغتين العربية والإنجليزية مع ضبط تلقائي للاتجاه (RTL / LTR).
- **إدارة السلة والدفع التفاعلي**: محرك سلة حي يحسب الأسعار ومصاريف التوصيل وتوليد أرقام الطلبات.
- **طرق الدفع المحلية**: دعم الدفع نقداً عند الاستلام، والتحويل عبر بنك الكريمي، ومحفظة ون كاش، ومحفظة بيس (PYS).
- **عزل الصلاحيات وحماية البيانات (`GhaymAuth`)**: نظام أمني مبني على الأدوار لمنع الوصول غير المصرح به.
